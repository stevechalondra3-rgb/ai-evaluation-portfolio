# Prompt Testing & AI Behavior Analysis

## Overview

This project demonstrates structured testing of AI systems using
different prompt types and edge cases.

## Test Categories

- Normal prompts
- Ambiguous prompts
- Multi-step instructions
- Adversarial prompts
- Edge cases
- Contradictory instructions

## Evaluation

Each response is reviewed for:

- Instruction adherence
- Accuracy
- Consistency
- Safety
- Reasoning quality
- Unexpected behavior

## Skills Demonstrated

Prompt Testing · LLM Evaluation · QA · Edge-Case Analysis
