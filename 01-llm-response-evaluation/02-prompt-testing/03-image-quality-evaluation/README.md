# AI Image Quality Evaluation

## Overview

This project demonstrates a structured method for evaluating
AI-generated images against a given prompt.

## Evaluation Criteria

- Prompt adherence
- Object presence
- Composition
- Visual quality
- Missing elements
- Unwanted elements
- Image modifications

## Example Labels

- Same / No Modifications
- Minor Modifications
- Heavy Modifications
- Different

## Skills Demonstrated

Image Evaluation · Visual QA · Annotation · Quality Assessment
